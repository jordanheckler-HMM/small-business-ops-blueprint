# Glossary

New here? Start with the [plain-language Start Here guide](start-here.md).

These are working definitions for this blueprint, not claims about any particular product's capabilities.

- **AI assistant:** A user-facing system that helps interpret requests and produce responses or take permitted actions.
- **Agent orchestration:** Coordination of an assistant's tools, steps, and workflows under defined permissions and review.
- **Knowledge/context layer:** An organized source of information that an assistant can consult when responding or carrying out a task; for example, a set of approved product FAQs the assistant can check when answering a customer question.
- **Local memory:** Information retained in a user-controlled local store to support continuity between interactions.
- **Provider-neutral:** Describing a role or principle without requiring a particular vendor, model, or product.
- **Reference architecture:** A conceptual arrangement of components that illustrates roles; it is not by itself a tested or deployable system.
- **Task verification:** Checking a result against evidence appropriate to the task, rather than treating a completion message as proof.
