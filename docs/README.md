New here? Start with the [plain-language Start Here guide](start-here.md).

## Reference layers

The examples use Hermes for assistant/orchestration, local-memory for local persistence, and GBrain for knowledge/context. These names identify example roles only; this document does not claim the tools interoperate, endorse them, or provide setup instructions. The intended architecture is provider-neutral, and equivalent components may be substituted.

When describing an implementation, keep conceptual guidance separate from tool-specific instructions and refer readers to official upstream sources for current project information. No third-party documentation or configuration is reproduced here.
