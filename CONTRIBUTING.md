# Contributing

Contributions that make this blueprint clearer, safer, or more useful are welcome. You do not need to know GitHub or Git to understand the documentation or suggest an improvement. You can describe a correction or question in an issue, or propose an edit if you are comfortable doing so.

## Helpful contributions

- Explain an unclear term in plain language.
- Improve the structure or accessibility of the docs.
- Point out a safety concern or an unsupported claim.
- Suggest a provider-neutral principle or identify where an example is specific to one tool.

Please keep proposals focused. This repository is currently documentation-only; do not assume a working setup or tested procedure exists.

## Protect private information

Use fictional placeholders such as `[BUSINESS_NAME]` and `[EXAMPLE_VALUE]`. Never include credentials, tokens, private profiles, customer or employee data, private machine paths, or other confidential material in an issue, contribution, screenshot, or example. Review changes before sharing them publicly.

## Plain-language standard

Write so that a small-business owner unfamiliar with GitHub can follow the content. Explain unavoidable technical terms, distinguish examples from requirements, and link to authoritative upstream project pages rather than copying their documentation or configuration.
